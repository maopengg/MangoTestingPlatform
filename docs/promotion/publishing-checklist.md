# 社区发布检查清单

## 内容核验

- [ ] 标题没有“最强”“第一”“完全替代”“零代码解决所有问题”等无法验证的表述。
- [ ] 功能在对应公开版本中可用，Beta 或计划中能力已明确标注。
- [ ] 服务端、前端和执行器版本一致。
- [ ] 文章中的菜单名、产品名和帮助文档保持一致。
- [ ] 没有承诺未经确认的发布日期、兼容范围和服务等级。
- [ ] 同一正文针对渠道调整了标题、开头、标签和行动引导。

## 链接核验

- [ ] Gitee 与 GitHub 仓库可访问。
- [ ] 在线演示可访问，并且注册、登录和核心演示链路正常。
- [ ] 帮助文档首页与文中具体章节可访问。
- [ ] 执行器下载地址有效，文件版本与服务端匹配。
- [ ] 文章没有引用内部仓库、内网地址或尚未公开的 Issue / 文档。

## 安全与隐私

- [ ] 按 `screenshot-guide.md` 检查所有图片和视频。
- [ ] 未出现密码、Token、Cookie、Authorization、密钥和数据库连接串。
- [ ] 未出现真实业务域名、客户名、公司名、员工姓名、邮箱、手机号、IP 和主机名。
- [ ] 日志、请求响应、SQL、错误栈和文件名均已脱敏。
- [ ] 二维码仅保留作者和项目交流群，不包含无关推广。

## 发布与跟进

- [ ] 记录发布时间、渠道、文章地址和使用的版本号。
- [ ] 发布后 48 小时内集中处理安装、兼容性和复现问题。
- [ ] 可复现问题转为 Gitee 或 GitHub Issue，避免只停留在评论区。
- [ ] 将高频问题补回帮助文档，而不是长期复制同一段回复。
- [ ] 视频或长文发布后，把链接补充到仓库 README 和其他相关社区文章。
