# 分支到候选 Case 的规则

只有理解接口和相关业务调用切片后才使用；遵循入口 Skill 的底层依赖边界，不展开框架/SDK内部节点或分支。代码产生补充候选而非功能真理；称功能Case前与权威来源核对。

## 覆盖归属不变量

外部HTTP链发现的每个业务相关分支，且仅一个闭环归属：可执行HTTP自动化、单元、集成或明确Gap。不留未分类，推荐测试没建跑不算已执行；不可达不猜HTTP Case凑覆盖。

台账Gap不进受控下拉，集成不进依据；按最强证据用 `功能用例已核验`、`设计已核验`、`代码现状回归候选`，真实跨界才归集成。Gap状态 `current_status=deferred`（当前暂不处理），未决原因备注；依据三项、归属 `HTTP API自动化`/`单元测试`/`集成测试`固定。

单元叙述 `单元测试（非自动化测试职责）`，记源、隔离行为、建议位置、已知负责人；不建改跑/称完成，排API清单、完成分母、通过率。触发与隔离预期已证的单元推荐不是Gap，但实施状态明确。

逐分支至少记：稳定branch_id；接口、文件/符号/行；条件前置、结果副作用；四归属之一；API ID、单元集成引用或Gap ID；含非自动化职责的责任状态；静态映射及同修订运行命中。

绑定接口 `扫描基线提交`。新commit不只看文件行号，比较符号并沿全链、共享路由校验授权异常事务响应扩影响；直接/传递影响的所属接口重扫后才推进基线。可有多层支持测试，但闭环归属唯一，支持层记理由，不重复计数。

## 候选选择

每独立可控且外部可观察业务一个候选，不按语句、日志、赋值、helper、语法分支生成。

应用下表前先按入口 Skill 的“从测试角度描述 Case”核定业务目标及本条规则/风险，再用代码证据补触发与遗漏；表中技术结构不是用例标题或必须逐项生成的清单。每个候选须能说清测试角度、条件和独立预期，复用已有功能目标，不强制新列或固定标题前缀；候选独立不要求每个都新建一个真实 API Case，下游可组织为同一 Case 的多个场景。

| 代码证据 | 候选规则 |
| - | - |
| 必填/类型/枚举/正则 | 合法代表及产生不同结果的非法类 |
| 上下限/长度 | 可表达时min-1/min/max/max+1 |
| if/elif、switch/match | 覆盖不同结果/副作用，同结果条件可合 |
| 缺else/default | 追后续，HTTP结果未证则Gap |
| 复合条件 | 用判定表，优先pairwise，高风险明确要求时MC/DC |
| null/空/零/缺失 | 仅行为不同拆 |
| 认证/权限/租户/归属 | 适用成功、未认证、无权限、跨租户、非所属；真相同可复用中间件覆盖 |
| 对象查找 | 仅可达的存在、不存在、软删、错租户、歧义 |
| 状态 | 合法、重要非法迁移类、重复幂等、终态 |
| 幂等/唯一键 | 实现存在时首次、同重放、冲突重放 |
| 事务 | 成功及稳定可控失败证明回滚一致 |
| 外部客户端 | 支持Stub/环境可控才成功/失败/超时/不可用/格式错 |
| 异步/回调 | 有确定控制才生命周期/重复乱序 |
| 集合/循环 | 仅结果不同时0/1/多/最大/重复/排序 |
| 文件 | 实现存在时有效、空、坏、超限、不支持、内容后缀不符 |
| 分页 | 可观察的默认/边界/空页/最大/溢出/稳定序 |
| 异常映射 | 显式稳定API映射，不强制造任意内部异常 |
| 报告下载 | 适用状态、类型、文件名、签名、范围筛选、再生成 |

## 互斥与多命中

多出边不自动互斥。单次if/else、单值switch、状态判断互斥，同Case同求值点不能声称两结果。集合逐项可多结果，须对照数据及断言证明每条。广播/聚合/独立检查可同时走，用标注非互斥矩形，不菱形。不知互斥/重复/独立时Gap，不全选。

covered_node_ids/covered_branch_ids是连通子图不必线性。单源多出边时，在前置、代码证据、业务判定记多命中原因；泛成功不证明全分支执行。

## 节点粒度与语义去重

节点是可审核业务阶段，不是单语句/赋值/helper/中间集合。以下全满足合为标准节点：同符号或不可分相邻符号；同对象贡献同外部结果；无独立可控决策/副作用/异常/依赖组件/职责边界；合法Case无法单独选控观其中一个。

如按类月计数、映射6月桶、补零通常一个 `统计并生成/零填充某类提醒的六个月结果`，不因语句不同拆计数构建映射补零。校验、权限、外部、独立断言状态、异常或可独立控制分支等真实边界分开；明确测上游过滤/规则的区别可独立。

上传前逐相邻核：同源/不可分调用？同对象产物？标签仅实现动词不同？总是相互输入且无独立边界？全部合法Case总一起选？证一体则合，不把高层输出与计算双建供不同Case挂载。共用标准结果节点，差异在上游分支/断言。

修图选稳定标准ID，删被替代节点/边，同一次增量原子更新Mermaid及全部受影响Case选集；回读全流，不留悬空旧ID。

## 分派到具体处理器

字段/枚举/操作/策略/registry驱动不能止于文本/日期/权限/动态字段大类。沿switch/factory/map/registry/lookup追到改变独立行为的具体processor/builder。

具体处理器、查询条件/嵌套路径、副作用或异常不同则分路，节点/边ID来自稳定语义/源码身份非行号。一次请求可多discriminator时矩形遍历/分派，只有受控多项和断言证明可共走才Case多选。

不因枚举名、标签、夹具、预期值不同就拆；源码同符号等价行为共节点子图，逐Case留理由。

上传前和回读后按精确节点边选集分组，不同判别/声称行为碰撞时：逐追具体handler/条件/路径/副作用/异常 → 真等价才接受并解释 → 否则同扫描补路更新所有选择 → 回读Case-flow核具体目标。只大类碰撞是模型错非页面切Case失效；真共享不能为视觉不同硬拆。

## 分发、汇合与单入口结果

并发广播集合独立工作完才共享builder/mapper/响应/事务/后续时，图须矩形分发（明示可共走）→ 有源码分支工作 → 矩形等待聚合汇合 → 共享后续一次。

所有完成分支入汇合，不另画内部支路直达已由汇合/共享构建到达结果的捷径，否则混数据来源与控制流，像重复执行。

多入边节点必须证明互斥收敛只执行一次、独立分支显式汇合，或有标签的故意循环。否则拓扑不明先修。内部计算先汇合，外部结果一次构建，不同时做内部计算/恒执行输出分发的目标。

`无匹配`、`空集合`、补零放真实求值点：一次空非空菱形互斥；恒执行builder内按类补零通常属同结果节点，以数据、必要源码决策和断言区别。不可能共存时不把全局无匹配画成多命中类分支兄弟。

返回值丢弃也不自动无关：异常超时、副作用、事务、同步或必须完成能影响外部则保为非输出上下文；仅源码证无外部影响才省略并留证。

上传核每分发必要汇合、共享操作单语义入口、无绕汇合捷径、互斥菱形/多命中标注矩形、影响行为全入图或有据省略、Case选集修后连通。

## 可达性过滤

先归属再可行：

1. 单服务直调，响应/schema/服务持久断言归HTTP。
2. 工厂前置仍HTTP，缺模型模板需建不证明集成；仅测试环境则非生产标签不延期。
3. 真实服务/消息/worker/第三方/分布事务/最终一致边界为目标才集成。
4. 归属后pending/deferred，不用可行性改职责，无真实绑定不completed。

每候选有据回答：请求/身份/DB/时间/Stub可控触发？HTTP/支持查询/事件文件/获准DB可观察？运行确定隔离可清？预期权威还是明确代码候选？

全事实已知且权威一致→功能已核验；代码事实齐无权威→代码候选；行为知但所有合适环境无安全控观清→正确依据下deferred完整场景；触发/判定/可达/冲突/清理不明→Gap不猜；无HTTP效果内部行为排API，必要时留审核理由。

可行性跨可用适合环境，不只当前；测试可控可清而生产不适仍pending_create、非生产scenario_tags，生产资格是分类非创建前提。

## 语义去重与标题

case_title自然准确业务目标，与场景断言一致，可追溯号及必要条件结果保留；纯产品模块客户端环境标签移除；不堆原枚举、字段、数码、ID、赋值、HTTP、方法、维护说明。上传交接和回读都查，违规先修。

标题要求不限制 `test_scenario` 的句式。场景写明测试条件和操作。复现确需枚举、字段、错误码、ID 或请求值时，同时说明其业务含义。独立可验证的预期写入 `core_assertion`，代码定位写入代码证据。

标题用实际业务动作和可观察结果表达测试目标，必要时写出决定结果的状态、权限或输入条件。原始枚举、协议状态和请求参数按需保留在场景、断言或证据中。

编号前身份：

`method + normalized path + version + precondition/state + trigger + observable outcome + side effect`

同身份即使标题标签优先级样ID夹具文件行号顺序不同也合，主行保全部有用定位。版本契约行为不同不合；共享handler等价则一功能模型加版本执行变体，接口清单保各路由。

标题/向量/词/路径相似只是提示，合前比触发结果契约副作用权威；无法证等价则Gap不猜。先台账去重，创建前再对平台去重。

## Gap 内容

原因类别及恢复要求统一遵循入口 Skill 的“链路未完成与暂不编写原因统一说明”。链路未解析、测试依据未明确属于待取证，不因暂存为“暂不处理”就称已证明不适合自动化；无页面调用、禁写和职责排除也不等于链路无法解析。

逐未决记Gap ID/范围接口、已证事实源码、具体缺失冲突、为何不能正确请求/判定、下一动作/已知负责人/安全恢复点。共享路由、授权租户、异常、事务、清理受影响要明确项目级范围。
