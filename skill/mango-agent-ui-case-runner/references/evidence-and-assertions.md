# 证据与断言规则

按以下顺序优先选择证据：

1. 准确的 DOM 属性、URL、标题、可见文字、数量、启用/选中/输入值状态；
2. 当前获授权浏览器会话可见的网络或产品响应；
3. 对应当前步骤的截图；
4. 仅当确定性证据无法表达保存的判定标准时，使用视觉语义判断。

每条断言记录简短名称、类型、预期值、实际值、状态及有关签名附件引用。不得用上一条步骤的截图证明当前状态。

失败证据应展示相关页面状态，避免不必要地暴露个人信息或秘密；适当时通过现有浏览器工具裁剪或脱敏。禁止上传 Cookie、local-storage 完整内容、授权头、密码、API key 或原始环境配置。

视觉或语义断言必须说明判断的可观察特征，以及为什么符合或违反判定标准；置信度本身不是证据。
