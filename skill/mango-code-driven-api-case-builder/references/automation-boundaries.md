# 自动化与数据边界

<a id="mandatory-configuration-write-exclusion"></a>
## 配置禁写硬边界

代码驱动在测试、预发、生产、隔离环境均不得改环境/服务运行配置、系统/租户管理控制、额度/权益、授权。普通业务对象不因可复用或叫规则/配置/模板/管理就被禁。

- 禁止全局/租户功能开关、运行参数、服务依赖地址、认证授权策略、AI点数/额度权益、基础设施/模型服务配置、灰度控制，因它们控制运行、共享服务、权益或安全；租户范围本身不够判禁。
- 规则库规则、规则组、清单、客户业务模板的生命周期CRUD可测。后续业务复用、名叫规则配置管理或被service读取都不自动变系统配置。本轮隔离对象须权威代码、归属范围、业务断言及失败安全清理；前置不改共享/历史、全局默认、现用共享策略、原角色权限或环境控制。同对象兼有禁控影响时分离安全路径，不按模块名整块排除。
- 按controller/service写路径、归属、对象集、副作用判断，先读代码上下文解决未知，记录业务CRUD/运行安全控制依据，不凭HTTP、表名、可复用或一次成功。旧排除若仅标签判断须重审，合格业务恢复待自动化，不造执行绑定证据。
- 禁止配置创建、更新、删除、启停、重置、导入、发布、应用。其正常/负例/权限/边界也不创建可执行Case；预期拒绝不保证产品Bug时不会真写。
- 审完整目标、前置、工厂/SQL/脚本、API、异步、后处理、清理恢复。业务需改配置才能运行则改为只读使用已合适配置；无合适配置排除，不改环境。
- 排除项不创建、扩展、复用、绑定、调试、执行或发布；仅测试、专属租户、临时验证、执行后恢复、全模块都不例外，不向用户请求绕过批准。
- 接口清单与代码证据保留。已证禁控的未绑定场景记 `deferred/not_applicable`，`remark` 写具体控制/影响，不泛称业务配置管理。禁项不造Case/不称完成；已绑定保ID/历史，仅报告，不执行/静默删解绑改状态，退役另走治理授权。
- 配置查询只有全流程无写才可，含隐式初始化/读时写；交接前从代码解未知，不发试探写确认安全。

禁令针对被测应用。合格业务所需平台Info/Case请求、断言、绑定和获准工厂编辑仍可，不能借此间接改被测配置。

角色权限授权只查询，禁增改删启停复制导入重置、授撤、绑解菜单/数据范围、分配移除角色、改成员；临时隔离角色用户、预期拒绝、API/工厂/SQL/脚本前置和清理均禁。普通业务权限/租户检查可只读用现有身份，缺身份不通过改授权解决。

## 可行性检查

未完成或暂不实施原因统一使用入口 Skill 的“链路未完成与暂不编写原因统一说明”，不另建原因分类。区分待取证与已确认排除，具体原因、已查/已尝试证据、下一步和恢复条件缺一不可；仅缺工厂模型、前置未实现或清理尚未设计仍是实施工作。

确认场景只有触发/预期准确、请求身份状态可控、HTTP/业务/schema及必需副作用可机验、至少一可访问环境确定运行、修改隔离且清理/回滚可验时，才 `current_status=pending_create`。

当前环境可切换，不是身份/可行性限制。生产风险先评估非生产；测试安全完整而生产不适时保持pending_create、合适非生产标签并切环境，不因不能生产打deferred/0/0。

行为已知且所有可用合适环境都无法满足必要安全控制、观察、清理或平台能力时，才可据证据记为条件/能力原因的暂不处理；无页面调用、禁写及职责排除分别按入口规则，不混成平台能力问题。行为或预期不明先记分析缺口，继续取证，不伪称已确认排除。只有真实绑定才 completed，可行不等完成。

单元归属写 `单元测试（非自动化测试职责）`，记代码和隔离断言，止于文档。用户未扩围不建改跑单测，也不进ApiCase完成/通过分母。

## 数据策略

前置方式不决定职责。多表/工厂/服务持久化断言不自动集成；触发与判定仍单服务API边界就HTTP。

报数据平台Gap前，MCP确定产品并切可用测试环境，核逻辑数据源、真实绑定、表、实体模板及清理。可用DB忠实表达时，缺实体模板归工厂实施，API Skill编排；保持pending_create，不deferred或转集成。

每Case明确策略之一：无需前置并说明；支持的公共API；已证逻辑/真实绑定工厂；全局公共变量运行解析环境维护前置，核租户状态归属资格，不存固定夹具ID名或解析值；隔离E2E准备链；有据不执行。

查询与修改许可分开。查询只读发现真实值后精确查，独立包含/排除断言；创建可查合格共享前置不改删。遵循API优先、允许只读SQL、再工厂，不绕归属。

删除每轮业务API/获准工厂造专属并捕精确ID，含逻辑批量及所有HTTP。禁止API/SQL选存量删，以免删他人/耗尽数据；只可查本轮目标/结果，失败缺失不换共享历史，批量范围无法证明停对应场景；失败仍有本轮兜底清理，交接/可行判断前须归属证据。

表名、SQL片段、夹具ID、静态声明不证明运行有效。工厂Skill负责实体/schema、模板、依赖、值、预览、清理；API Skill执行前核环境身份、绑定、执行清理。

不在查询、预期、SQL/脚本、前置、工厂覆盖、清理固化环境业务值，须变量、当前环境资格查询、响应缓存或本轮造数。契约常量/故意非法边界不算前置；缺动态数据不授权历史ID回退或改配置权限。交接保留并遵循 [运行数据门禁](../../mango-api-case-builder/SKILL.md#mandatory-runtime-business-data-resolution)。

## 修改策略

- 除代码证只读外，POST/PUT/PATCH/DELETE按写。
- 先配置禁写，恢复/隔离不使禁写可测。
- 业务增改删只在批准非生产、隔离数据、清理已验时自动化。
- 破坏性清理优先工厂或只删本轮的公共API。
- 禁宽清理、共享类生产记录、猜ID、未核SQL。
- 重要副作用验证预期发生且非预期未发生。

## 依赖与故障

不编超时、依赖错、回调、重试或竞争结果。仅支持的Stub/注入/可控时钟/确定环境可自动化，否则已确认场景记不可自动化，结果不知则Gap。

当前平台缺Stub、注入、额外租户身份、预期错误执行、时钟、runner或其他不能靠普通工厂资产补的能力，记 `测试平台能力 Gap`，保原 `测试归属`，`current_status=deferred`（当前状态暂不处理），备注精确启用条件，排完成/通过分母。不擅自实现平台能力。

## 认证与秘密

用下游授权管理/环境变量，不把真实token、Cookie、密码、DB凭据、个人信息放Case、台账、扫描产物或对话。

## 执行边界

本Skill只判可交接。工厂Skill拥有数据实体模板依赖值预览清理；API Skill拥有产品、授权、步骤、执行诊断清理回读，不在此重复下游schema。
