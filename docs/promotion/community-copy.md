## 开源交流群版本

分享一个持续维护中的开源项目：MangoTestingPlatform。

技术栈是 Django REST Framework + Vue 3 + TypeScript，采用前后端分离和独立执行服务。平台统一管理 API、UI 和 Pytest 自动化，并包含数据工厂、Scheduler、API Worker、执行器、报告中心和 MCP Service。

项目采用 AGPL-3.0 协议，支持 Docker Compose 部署。如果你对任务调度、测试数据生成、远程执行或 AI + 测试平台感兴趣，欢迎交流或提交 Issue。

Gitee：https://gitee.com/mao-peng/MangoTestingPlatform

GitHub：https://github.com/maopengg/MangoTestingPlatform

## 朋友圈版本

最近继续完善了自己维护的开源项目——芒果测试平台。
