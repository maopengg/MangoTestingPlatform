# 短视频脚本

适用渠道：视频号、抖音、小红书视频。建议时长 60～90 秒，竖屏 9:16；一条视频只讲一个问题，不把所有菜单塞进同一期。

## 方案 A：自动化难的不是写出第一条脚本

### 封面

```text
自动化测试
难的不只是写脚本
```

### 口播与画面

**00:00—00:08**

画面：脚本、环境、测试数据、定时任务和报告分散在不同位置的简图。

口播：

> 自动化测试最难的，往往不是写出第一条脚本，而是半年后还有人敢改、敢跑、能快速看懂为什么失败。

**00:08—00:28**

画面：最新版脱敏的项目导航、API 用例和数据工厂页面快速切换。

口播：

> 我做的开源芒果测试平台，把 API、UI、Pytest、测试环境和测试数据放进同一个系统。用例执行前可以按业务状态造数，执行中引用结果，结束后再按策略清理。

**00:28—00:48**

画面：任务执行和报告详情。

口播：

> Worker 和执行器负责运行任务，报告保留请求、响应、断言、日志和失败截图。一次失败不只是红色状态，而是能继续排查的完整上下文。

**00:48—01:05**

画面：MCP 工具调用与最终总结。

口播：

> 平台还通过 MCP 把真实测试资产和报告提供给 AI，让它辅助维护用例和分析失败，而不是只生成一段没人管理的脚本。

**01:05—01:15**

画面：仓库首页与项目名。

口播：

> 项目已经开源，搜索 MangoTestingPlatform。适不适合你的团队，可以先看演示再决定。

## 发布文案

芒果测试平台是一套可私有部署的开源质量工程平台，覆盖 API、UI、Pytest、测试数据、调度执行、报告和 MCP。最新版继续建设研发协同、性能测试、Mock、UI 自愈和质量效能，相关能力会按版本逐步开放。

项目地址：https://gitee.com/mao-peng/MangoTestingPlatform

## 拍摄要求

- 使用完全脱敏的演示账号和演示项目。
- 每个页面停留至少 2 秒，关键区域放大而不是高速扫过。
- 字幕不要遮挡按钮状态、步骤结果和错误信息。
- 首页、报告和 AI 页面优先使用真实运行结果，不使用静态概念图冒充产品截图。
- 最新版未公开能力统一加“最新版预告”角标。
