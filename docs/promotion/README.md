## 使用建议

1. TesterHome 首发时优先链接 Gitee，并在评论区持续回答部署和使用问题。
2. OSCHINA 投递稿可以直接用于软件库介绍，技术文章另行拆分。
3. 社群文案按场景选用，不要在同一群重复发送多个版本。
4. B 站视频发布后，将视频链接补充到 TesterHome、OSCHINA 和仓库 README。
5. 对外统一使用“芒果测试平台”或“MangoTestingPlatform”，避免临时更换产品称呼。
6. 根目录现有 GIF 来自历史版本，只用于说明产品形态；发布长文和视频前应按[截图与脱敏规范](screenshot-guide.md)补充最新版素材。
7. `release-7.1.1.md` 可直接用于预告尚未全部开源的能力，但必须保留“最新版预告、分批开放”的说明，不能让读者误认为公开仓库当前已包含全部功能。
8. 同一篇正文可跨平台复用观点，但标题、开头和行动引导应按渠道调整，避免完全相同的机械分发。
